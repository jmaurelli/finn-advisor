# Finn Advisor

Personal budgeting application, with a Replit-designed React/Vite GUI currently branded **Tallywell**. HumanLayer owns backend design and implementation on server02.

The frontend is a synthetic-data prototype, not a working financial service. Its edits reset on refresh. No authentication, persistent database, CSV import, or financial API is connected.
